# Design direction

Use a light canvas, dark blue text and a clear blue action color, with yellow reserved for the selected journey moment. Use the existing system font stack and supplied artwork.

Keep one main navigation. Journey links go directly to the inline homepage content; the seven moments reveal the capabilities for that part of the work. The library provides search and filters across 33 distinct capabilities.

Use generous space, readable line lengths, direct labels and native media controls. Preserve captions, transcripts, reduced-motion behavior, keyboard navigation and useful content before JavaScript runs.

The proposed knowledge journey stays separate from the narrated build journey. Writing and notes link directly to the blog. Capability pages keep their own purpose, first step, prerequisites and source.

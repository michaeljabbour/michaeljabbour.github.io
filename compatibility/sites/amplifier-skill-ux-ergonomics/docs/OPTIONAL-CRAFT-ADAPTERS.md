# Retained visual references and native adapters

UX Ergonomics uses task evidence, authority and appropriate validation to decide what should change. Its credited visual-craft references are optional material. They do not require the older Taste bundle, its framework defaults, agents or recipes.

The [older Taste bundle](https://github.com/michaeljabbour/amplifier-bundle-taste/tree/4cf2f37465d1a93d3e22e653ee92fe078eb07280) remains the actual home of native assets not physically moved into this package. It is distinct from the authored Taste × Elegance method. Keep the source identity, credits and experiment history; neither unmeasured adoption nor age establishes that an asset has no value.

## What is included here

`skills/ux-ergonomics/references/sources/amplifier-bundle-taste/` includes the source license, eight substantial aesthetic/output/redesign reference bodies, two supporting context files and `scripts/check-tells.sh`. The [visual craft guide](../skills/ux-ergonomics/references/visual-craft.md) states their role. These are credited snapshots for deliberate inspection, not a second installed Taste entry. A pattern flag is not a measured usability finding.

# Accessibility evaluation

## Layers

1. Automated checks for detectable failures.
2. Source and semantic inspection.
3. Keyboard, focus, zoom, reflow, motion, timing, error, and authentication testing.
4. Screen-reader and other relevant assistive-technology operation.
5. Cognitive accessibility review.
6. Representative task testing with affected users when consequence warrants it.

For every finding name the barrier, affected interaction, relevant criterion or pattern, severity, confidence, remediation criterion, and verification step. Never claim full conformance from a subset of layers.

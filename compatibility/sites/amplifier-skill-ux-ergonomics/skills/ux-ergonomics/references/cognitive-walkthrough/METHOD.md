# Cognitive walkthrough

For each action ask:

1. Will the user form the right goal at this point?
2. Will the user notice the correct control or information?
3. Will the user associate it with the desired result?
4. After acting, will the user understand the system response and know what to do next?

Record the user knowledge assumed, evidence available, likely failure mechanism, consequence, and recovery. Walk the actual interface state when possible. A walkthrough is expert inspection, not observed-user evidence.

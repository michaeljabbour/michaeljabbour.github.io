# Adversarial ergonomics

Inspect interactions that pressure, manipulate, misdirect, or exploit people or agents.

## Human-directed risks

- false urgency, scarcity, authority, or social proof
- anthropomorphic pressure and relational obligation
- obscured consequences or asymmetric choices
- consent fatigue, obstruction, confirmshaming, and disguised advertising
- confidence displays that exceed evidence
- conversational persistence after refusal
- defaults or memory that silently expand scope

## Agent-directed risks

- manipulative interfaces that steer a computer-use agent away from user intent
- prompt injection or content that impersonates system authority
- completion pressure that overrides privacy or safety constraints
- UI patterns that cause unintended purchases, disclosures, subscriptions, or permissions
- goal drift caused by intermediate instructions or deceptive state

## Review method

1. State whose interests each interaction serves.
2. Identify pressure, concealment, asymmetry, obstruction, and impersonation.
3. Test whether a reasonable human or agent could detect the manipulation before consequence.
4. Preserve user intent as the governing objective.
5. Add verification or intervention proportional to consequence.

Do not label ordinary persuasion as a dark pattern without evidence of deception, obstruction, or conflict with the user's interests.

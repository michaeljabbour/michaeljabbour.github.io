Start from the public source

git clone https://github.com/michaeljabbour/amplifier-capability-teaserkit.git
cd amplifier-capability-teaserkit
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/teaserkit --help

Use the native package and command interface described in the installation guide. This capability does not require a portable skill.

  • Python 3.11+, ffmpeg and Playwright Chromium are required for a full build.
  • The deterministic library/CLI works without an AI provider. Optional plan, explore and review use the separately configured ai extra.
  • Install the package first, inspect teaserkit doctor, then install any missing browser or renderer prerequisites deliberately.
  • The shown virtual-environment commands use macOS/Linux paths; on Windows, use the corresponding .venv\Scripts executables.

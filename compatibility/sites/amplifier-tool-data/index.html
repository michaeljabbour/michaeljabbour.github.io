Amplifier Data

Keep the evidence. Change the view.

An independent Python storage library for tools that need exact source bytes, durable history and room to evolve. Memory is one consumer; your own capability can be another.

Three copies. No original.

In 63 seconds, one true sentence goes into three tools and comes out as three versions. Amplifier Data keeps the original once, as exact bytes on a log that only moves forward. Each tool builds its own view that points back home, and after the lights go out the original comes back byte for byte. It is a library for builders: it keeps evidence honest and does not promise smarter answers. Captions are on the player; a transcript is below.

Use it when

  • Your application needs exact retained evidence plus derived summaries or indexes.
  • Multiple capabilities need the same storage substrate while keeping independent schemas and models.
  • You want a local native log you can close, replay and inspect.

Choose another route when

  • You need a turnkey end-user memory app or hosted database service.
  • Your retention policy requires immediate physical deletion from an append-only file.
  • You need validated production support or Windows native acceptance today.

Read the canonical method

Store exact bytes as content-addressed Cells in an append-only log. Derive scopes, relations and query lenses over that log. Keep models, interpretation and consumer schemas outside the storage library. Preserve the source log for replay and regeneration.

Limits and prerequisites
  • Alpha library. Durable paths require the native Rust kernel; the Python source fallback is in-memory only.
  • One writer owns a durable file; multi-process access uses the companion server/RemoteStore seam.
  • Invalidation does not erase bytes from an append-only log. Keep original logs and review retention separately.
  • The supplied binary wheel is macOS Apple silicon only. Source-built native acceptance also passes on Ubuntu 24.04/Python 3.12; other platform/toolchain combinations remain unverified.

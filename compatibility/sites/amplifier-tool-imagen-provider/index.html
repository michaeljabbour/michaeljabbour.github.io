Imagen Provider

Generate the image without losing the requirements.

For agents and developers adding image generation. Imagen Provider exposes one library, CLI and MCP interface, qualifies the configured provider against requested features and returns image paths and metadata through the same integration.

Limits and prerequisites
  • Provider invocation can cost money and requires an approved environment credential. Selector/mock tests do not generate images.
  • The parked video-mcp stub is retained separately as reference; it is not advertised as a functioning video provider.
  • Server defaults to environment-only configuration; IMAGEN_MCP_CONFIG_PROFILE=local explicitly enables the retained dotenv setup profile.

git clone https://github.com/michaeljabbour/amplifier-capability-imagen-provider.git
cd amplifier-capability-imagen-provider
python3 -m venv .venv
.venv/bin/python -m pip install .

Use the native package and command interface described in the installation guide. This capability does not require a portable skill.

  • Native distribution: imagen; command: imagen; MCP entry point: python -m imagen_mcp.
  • Generation needs an approved OpenAI or Gemini credential and may incur provider charges.
  • The default config reads environment variables only. IMAGEN_MCP_CONFIG_PROFILE=local explicitly opts into the retained dotenv profile.
  • The shown virtual-environment commands use macOS/Linux paths; on Windows, use the corresponding .venv\Scripts executables.

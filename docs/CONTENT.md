# Portfolio content

The catalogue covers 33 public capabilities and gives each one a primary task category. Categories are navigation, not an instruction to install everything or a claim that the collection runs as one integrated product.

Names, repository paths, intended functions and constraints were checked against the capability sites and their published metadata on October 29, 2026. All 33 destination sites expose the selected installation anchor: `#install` on shared sites and Decisioncraft, or `#use-skill` on the five original skill reference sites and Project Handoff. This checks navigation, not whether each native runtime is installed on the visitor’s computer.

The introduction describes the work rather than inventing a job title, customer roster, institutional affiliation or personal biography. Project copy describes intended use. It makes no adoption, superiority, accuracy, cost-saving or customer-outcome claim. Every output is a fictional illustration, and suggested first-use text does not report a completed execution.

## Distinct jobs

- Data is a shared storage library. Memory is one consumer. Handoff is a small independent plain-record skill and needs neither.
- Imagen Studio directs and reviews images. Imagen Provider exposes native image mechanisms through stable interfaces.
- Sizzle directs a film before generation. TeaserKit records a real web interface from a repeatable storyboard.
- Decisioncraft maps a decision. Fast Decisions concerns measured routing choices in an agent session.
- Cognitive Simulation frames explicit hypotheses and model predictions, never real participant evidence.
- Build with Amplifier, Tauri and Torque are alternative specialisms, not mandatory layers of one application.
